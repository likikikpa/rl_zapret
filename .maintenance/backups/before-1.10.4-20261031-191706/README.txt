============================================================
  ZAPRET + GAME OPTIMIZERS — для Rocket League и CS2
============================================================

Что это:
  - zapret обходит DPI-блокировку и оптимизирует игровой трафик
  - RL Optimizer.exe — управлялка для Rocket League
  - CS2 Optimizer.exe — управлялка для Counter-Strike 2

------------------------------------------------------------
УСТАНОВКА
------------------------------------------------------------

1. Распакуй всю папку куда удобно (например, на Desktop).

2. Запусти нужный optimizer:
   - "RL Optimizer.exe" для Rocket League
   - "CS2 Optimizer.exe" для Counter-Strike 2
   - Антивирус может ругаться (PyInstaller exe часто триггерит
     ложные срабатывания). Добавь в исключения.
   - При первом запуске Windows SmartScreen может спросить —
     "Подробнее" -> "Выполнить в любом случае".

3. Нажми "Запустить Zapret (RL-режим)" или "Запустить Zapret (CS2-режим)".
   - Появится запрос UAC (права администратора) — соглашайся.
   - В трее или свёрнутом виде появится окно "zapret: ...".
     Это нормально, его можно свернуть.

4. ВАЖНО: одновременно работает только ОДИН zapret-режим.
   Если запустил RL и хочешь CS2 — сначала останови RL ("Остановить Zapret"),
   потом запусти CS2.

5. После запуска игры можно нажать "High Priority"
   для повышения приоритета процесса игры.

------------------------------------------------------------
ЕСЛИ НЕ РАБОТАЕТ
------------------------------------------------------------

Проверка 1: запустить bat вручную
  - Правый клик по "general (ALT9-RL).bat" или "general (ALT9-CS2).bat"
    -> "Запуск от имени администратора"
  - Должно открыться чёрное окно "zapret: ..." (свернутое)
  - Если окно сразу закрывается с ошибкой — читай ошибку

Проверка 2: конфликт с другим VPN/обходом
  - Если стоит другой zapret/GoodbyeDPI/ByeDPI/Proxifier —
    отключи их перед запуском этого
  - Команда в cmd: tasklist | findstr winws.exe
    (если что-то выводит — уже что-то крутится)

Проверка 3: ipset/обновления
  - Запусти "service.bat" -> вариант 7 (Update IPSet List)
    и вариант 8 (Update Hosts File)
  - Это обновит списки заблокированных IP

------------------------------------------------------------
ЧТО ДЕЛАЕТ КАЖДЫЙ РЕЖИМ
------------------------------------------------------------

ALT9-RL (Rocket League):
  TCP 80/443 + auth-порты (2053, 2083, 2087, 2096, 8443)
  UDP 443 (QUIC), UDP 19294-19344, 50000-50100 (Discord)
  UDP 7000-9000 (игровой трафик RL)
  UDP 21000-21999 (Epic Online Services)

ALT9-CS2 (Counter-Strike 2):
  Те же TCP/UDP базовые порты
  UDP 27000-27100 (игровой трафик CS2, matchmaking)
  UDP 4380 (Steam Datagram Relay fallback)

RL/CS2 правило: --dpi-desync=fake, repeats=4, cutoff=n1
  - Минимум фейковых пакетов = минимум лагов
  - Достаточно одного фейка для обмана DPI на старте сессии
